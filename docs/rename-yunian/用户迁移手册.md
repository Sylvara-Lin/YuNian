# 予念（YuNian）用户迁移手册

> 适用对象：原「恋语 / LianYu」用户升级到新版「予念 / YuNian」
> 核心结论：**新版是全新包名（`com.lianyu.ai` → `com.yunian.ai`）的独立应用**，系统不会自动搬运旧数据。请严格按本文档 **先备份 → 再安装 → 后导入** 的顺序操作。

---

## 0. 为什么需要手动迁移（一分钟了解）

Android 应用的数据隔离以「应用包名」为单位。旧版包名是 `com.lianyu.ai`，新版改为 `com.yunian.ai`，对系统而言是**两个不同的应用**，因此：

- 新旧版本的数据沙盒（聊天库、图片、语音、配置）互不相通，**不会自动继承**；
- 旧版「恋语」不会被新版覆盖，而是**并存**在两个独立图标下；
- 唯一可靠的搬家方式是「旧版导出备份 → 新版导入备份」。

> ⚠️ 迁移过程中**不要**先卸载旧版——卸载会连同旧数据一起清除。

---

## 1. 旧版「恋语」导出备份

**步骤**

1. 打开旧版「恋语」App。
2. 进入 **设置 → 通用 → 数据备份**。
3. 点击 **导出数据备份**。
4. 在列表里**勾选需要备份的联系人**（建议全选；可多次导出补齐）。
5. 点击 **导出**，系统文件选择器会要求你选择保存位置。
6. 保存文件，默认文件名为 `lianyu_backup_YYYYMMDD.lybk`，请记住保存路径（建议存到「下载」或网盘）。
7. **设置并牢记备份密码**（备份文件使用密码加密）。

**注意事项**

- 🚫 **务必记住备份密码**——密码仅用于解包该 `.lybk` 文件，遗失后无法恢复。
- ✅ 备份**包含文字、图片、语音等所有聊天数据字段**；文件较大时导出需要一点时间，请耐心等待完成提示。
- ✅ 建议**先把备份文件复制到电脑或网盘**再继续下一步，避免直接放在旧应用目录内。
- ✅ 若有多个联系人分组，导出完成后可再导出一份，双重保险。
- 🔎 校验：导出成功后确认文件存在且**大小不为 0**（正常为几十 MB 级）。文件名后缀必须是 `.lybk`。

---

## 2. 安装新版「予念」

1. 获取新版安装包 `YuNian-release.apk`（正式渠道获取，勿用来路不明的安装包）。
2. 点击安装；由于是不同包名，系统会作为**新应用**安装，**不会**提示覆盖旧版，**不会**自动删除旧版。
3. 安装完成后，桌面出现名为 **「予念」** 的新图标（蓝色系、圆角，图标上有「予念」字样）。

> 说明：新版启用签名与加固校验，请勿使用第三方重打包版本，否则可能无法启动。

---

## 3. 导入备份并校验

**步骤**

1. 打开新版「予念」。
2. 进入 **设置 → 通用 → 数据备份**。
3. 点击 **导入数据备份**。
4. 选择上一步导出的 `lianyu_backup_YYYYMMDD.lybk` 文件。
5. 输入**导出时设置的密码**。
6. 等待导入完成（导入按**联系人名称合并**，不会覆盖新版已有数据）。

**校验**

- 联系人数量是否与旧版一致；
- 随机点开若干会话，核对**最后一条消息**、**历史消息条数**；
- 抽查**图片、语音**是否能正常显示/播放；
- 确认自定义人设、世界书、角色配置等是否到位（如有）。

**注意事项**

- 若提示「文件格式不正确（非 .lybk 备份文件）」，说明选错了文件，请重新选择后缀为 `.lybk` 的备份。
- 若密码错误会导入失败，请核对密码（区分大小写）。
- 可重复导入同一备份做补齐，**不会**产生重复数据。

---

## 4. 微信（WeChat）重新扫码

新版包名已变化，旧版在微信侧的登录态/会话**不会继承**：

1. 打开新版「予念」→ 进入 **微信** 相关入口。
2. 按界面提示**重新扫码登录**。
3. 若二维码刷新失败或提示过期，返回上一级重新进入或稍后重试。

> 提示：扫码登录态与设备/包名绑定，属正常现象，重新扫码即可恢复。

---

## 5. 重新授权系统能力（Shizuku / 无障碍 / 电池白名单）

包名变化后，旧版获得的系统授权对新版**无效**，需要在新版上重新授予：

1. **Shizuku**：打开 Shizuku App → 授权应用列表中找到**新版「予念」** → 授权。（旧授权条目绑定的是旧包名。）
2. **无障碍服务**：系统 **设置 → 无障碍 → 已下载的应用** → 找到 **「予念助手控制服务」** → 打开开关。
   （旧条目「恋语助手控制服务」会随旧版卸载后自动消失。）
3. **电池优化白名单**：系统 **设置 → 电池 → 后台耗电管理 / 电池优化** → 找到 **「予念」** → 允许后台运行 / 不优化。
4. **自启动 / 后台弹出界面**（部分厂商系统）：在系统管家里把新版「予念」加入自启动白名单，保证消息能持续送达。

> 建议逐项确认一遍，否则可能出现「收不到消息 / AI 无法操控手机」等现象。

---

## 6. 推送配置（vivo / OPPO / 华为 HMS 等）

厂商推送（vivo Push、OPPO Push、华为 HMS Push 等）在开发者后台是**按应用包名 + 签名**注册的。新版包名 `com.yunian.ai` 与旧版不同，因此：

1. 需要在对应厂商开发者后台，为新包名 `com.yunian.ai`**重新申请 / 更新推送 AppID**（并上传新签名证书指纹）。
2. 华为 HMS 还需用新包名对应的 `agconnect-services.json` 重新打包/配置。
3. 在发版流程中同步更新极光/厂商推送的应用配置。

**如果不做这一步**：App 前台可正常收消息，但**退到后台或锁屏后可能收不到离线推送**。

---

## 7. 新旧共存与卸载

- 新旧应用**包名不同，可同时安装、互不影响**。
- 确认新版「予念」导入数据、微信扫码、授权、推送**全部正常**后，再卸载旧版「恋语」。
- 旧版卸载**不会**影响新版数据（新版已是独立沙盒）；但卸载旧版会**删除旧版沙盒**，请确保备份文件已另存。
- 建议保留旧版备份文件（`.lybk`）至新版本稳定运行一段时间后再删除。

---

## 8. 常见问题（FAQ）

**Q1：桌面图标怎么变了？**
A：新版品牌已更名为「予念」，图标更换为蓝色系圆角图标。新旧图标属于两个独立应用，可并存。

**Q2：需要注册/登录账号吗？原来的账号还能用吗？**
A：不需要，也没有账号可用。本应用**没有账号系统**：旧版「恋语」的登录入口从未实现真实后端（仅为历史遗留的界面残桩），新版「予念」已将其彻底移除。因此旧版不存在任何账号需要迁移，新版安装后**无需任何登录操作**即可直接使用。你的全部数据（聊天记录、人设配置等）只通过第 1、3 节的「导出 → 导入」备份文件迁移。

**Q3：聊天记录会自动搬过去吗？**
A：不会自动搬。必须通过第 1、3 节的「导出 → 导入」完成迁移。

**Q4：导入后数据不全 / 少了几个人？**
A：可能是导出时未勾选全部联系人；回到旧版补导一份再导入即可（按联系人名称合并，不会重复）。

**Q5：微信提示重新登录 / 收不到微信消息？**
A：包名变化导致登录态失效，按第 4 节重新扫码即可。

**Q6：收不到后台推送怎么办？**
A：优先检查第 5 节（电池白名单/自启动/后台权限）与第 6 节（厂商推送 AppID 是否已按新包名申请）。

**Q7：AI 无法调用无障碍能力？**
A：按第 5 节确认「予念助手控制服务」已在系统无障碍里开启，且 Shizuku 已对新版授权。

**Q8：能先卸载旧版再迁移吗？**
A：**不可以**。请务必先在旧版导出备份，再安装新版导入，确认无误后再卸载旧版。
