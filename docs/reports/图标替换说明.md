## 二、三个 bug 修复

### 1. 背景切换不立即生效、设置页不跟着变 ✅
**根因**：`BackgroundSettingsScreen` 与 `MainScreen` 的 `viewModel()` 作用域不同（NavBackStackEntry vs Activity），各自维护的 `_mainBgKey` 状态不同步。
**修复**：`BackgroundSettingsViewModel` 增加 `init` 监听 SharedPreferences（`chat_prefs` 的 `main_background` / `chat_background`），任何实例写背景 → 所有实例同步；`GlassPageScaffold` 改用 `viewModel().mainBgKey.collectAsState()` + `key(bgKey)` 强制重建 backdrop。

### 2. 二级页面内容超出顶部、点不到 ✅
**根因**：`GlassPageScaffold` 把 `topBar` 用浮动 `Box` 渲染（不占布局空间）且 `contentWindowInsets=0`，导致所有页面的 `content` 顶部顶到 header 下被遮挡。
**修复**：`topBar` / `bottomBar` / `floatingActionButton` 正确传给 `Scaffold`，content 的 PaddingValues 自动包含 header 高度。

### 3. 「背景设置」标题没居中 ✅
**根因**：header 用 `Row` + 固定宽度 `Spacer(40.dp)`，左右不对称。
**修复**：改用 `Box(contentAlignment = Center)` 绝对居中标题，返回按钮 `align(CenterStart)`。

## 五、踩坑记录

1. **Iconsax 引入 compileSdk 冲突**：`iconsax-compose` 的 Android 变体直接依赖 `androidx.core:core-ktx:1.17.0`（要求 compileSdk 36，项目是 35），导致 `checkReleaseAarMetadata` 失败。通过 `exclude(group="androidx.core")` + `exclude(group="org.jetbrains.compose.*")` 解决（Android 端用项目自己的 compose BOM + core-ktx 1.13.1）。
2. **Iconsax API 是顶层属性**（`val X: ImageVector`，`by lazy`），比 Lucide 的扩展属性更简单，直接 `Iconsax.Linear.X` 引用。
