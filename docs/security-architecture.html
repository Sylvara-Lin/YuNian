YuNian (予念) 安全架构全景图 — v2.0

Android 物理级防重打包体系 — HMAC-CTR | cert-in-salt | VMP P0-3 | InMemoryDEX | StrongBox证明 | F1 emulator | F2 APK hash | VMP指纹AAD

防御机制 (Defense)

  • • 内核级: HMAC-SHA256 CTR流密码 + 随机IV (阻统计攻击)
  • • cert-in-salt 88B: 证书哈希嵌入盐值,零if分支可Patch
  • • VMP P0-3: cert_obs[]→VMP bytecode LOAD_IMM,无.rodata常量
  • • InMemoryDexClassLoader: 业务DEX零磁盘落盘
  • • Poison fallback: cert^DE/AD,剥离Java cert=密钥全错
  • • Dex2C v2.1: 10个胶水方法, 11KB Native诱饵层(三层异构)
  • • KMS v2.0: 5级密钥体系, DK在NEON寄存器, dc civac清除
  • • VMP v3.0: 9个安全函数以VM字节码运行, 永不以ARM64存在
  • • Memory Guard: Guard Pages + Stack Canary + W^X检测
  • • APK签名绑定: 证书SM3 → 解密密钥, 无法脱壳重打包
  • • Body Encryption: WB-AES-256-GCM + 随机Nonce + 请求证明Token
  • • 国密全套: SM2签名 + SM3哈希 + SM4加密 + HMAC-SHA256

验证机制 (Verification)

  • • 启动链: JNI_OnLoad → ptrace → wb_aes CRC32 → KMS → integrity → bp_guard
  • • SO完整性: HMAC-SHA256(.text) + CRC32心跳(30s) + Shell DEX CRC32
  • • VMP信任锚: wb_aes_keycheck + kms_derive_sk + apk_sig_verify(全部VM内)
  • • 证书固定: 12个API Provider SPKI Pinning
  • • 设备指纹: AndroidID|SERIAL|Fingerprint → SHA-256 防篡改缓存
  • • 数据库密钥: Tink AEAD 硬件KEK + APK完整性绑定
  • • 预检Token: SM3(SO状态) → X-Lianyu-Proof Header
  • • 构建后验证: verify_release_apk.py 全量校验签名+SO+载荷

安全机制 (Security Controls)

  • • Fail-Close: DEX密钥绑定maps_crc→HMAC-SHA256, 注入检测+中毒
  • • ContentProvider: 剥离5个库Provider (HMS/AGConnect/WorkManager)
  • • Manifest: MainActivity单LAUNCHER, Gradle sourceSet壳修复
  • • 反逆向: 字符串XOR混淆 · OLLVM控制流平坦化 · 代码在VM内
  • • 反调试: ptrace自附加 · SW断点快照 · inotify监控 · signal handler
  • • 反注入: Frida/GUMJS/Gadget/Xposed/LSPosed/Magisk/Substrate检测
  • • 安全日志: Release全静默 · Critical用Log.wtf · 无stderr泄露
  • • 远程密钥: AES-256-GCM E2E · PBKDF2 · Android Keystore硬件隔离
  • • 零信任: PDP+PEP连续评估 → 威胁评分≥3 → KMS销毁+锁定降级
