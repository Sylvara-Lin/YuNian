# 予念 GDPR / 等保三级 合规自评

> 评估日期：2026-06-13
> 评估范围：予念 Android 客户端 (com.yunian.ai)

---

## 一、GDPR 合规

| 条款 | 要求 | 实现 | 状态 |
|---|---|---|---|
| Art.5 数据处理原则 | 合法、透明、目的限制 | API Key + 消息数据仅用于 AI 对话，用户协议声明 | ✅ |
| Art.6 合法性基础 | 用户同意 | AppSettingsStore 记录同意状态，首次弹窗 | ✅ |
| Art.15 访问权 | 用户可查看个人数据 | ProfileScreen 展示用户配置 | ✅ |
| Art.17 删除权 | 用户可删除数据 | BanScreen + 聊天记录删除 | ✅ |
| Art.25 数据保护设计 | 默认隐私 | C4 差分隐私（ε-Laplace）默认启用 | ✅ |
| Art.32 安全措施 | 加密、审计、持续评估 | AES-256-GCM、SM4、审计日志链、零信任 PDP/PEP | ✅ |
| Art.33 泄露通知 | 72h 通知监管 | SecureLog + 审计链可追溯异常 | ⚠️ 无自动通知机制 |
| Art.35 DPIA | 高风险处理需评估 | 高风险处理（AI生成内容）需补充 | ❌ 未做 |
| Art.44 跨境传输 | 充分性保护 | API Key 远程获取 + TLS 1.3 + 证书锁定 | ✅ |
